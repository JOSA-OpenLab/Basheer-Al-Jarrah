

> [!important] Core idea
> Some licenses look like open source but are **not OSI-approved**: BSL, SSPL, Elastic License, Functional Source License. They typically carve out one specific restriction — you can't offer the software as a competing hosted/managed service — and that single carve-out is enough to disqualify them.

## The Real Test: OSI Approval

The **OSI (Open Source Initiative)** maintains the official definition of "open source" and approves licenses against it. It's a formal standard, not a marketing term.

- These licenses keep everything else about the code visible and modifiable
- But the "no competing hosted service" restriction discriminates against a specific class of user (cloud providers) — which disqualifies them under the OSI definition

## How to Spot One

> If a license has language singling out **who can't use it commercially** — usually aimed at cloud providers — it's not OSI-approved, no matter how open the rest of the code looks.

## Why Projects Do This

AGPL triggers copyleft obligations on **network use**, but it didn't fully close the loophole for some companies: a cloud provider could host an unmodified (or trivially modified) version as a paid service without meaningfully "distributing" changes.

| Project | Moved From | Moved To | Reason |
|---|---|---|---|
| MongoDB | AGPL | SSPL | Stop cloud providers (e.g. AWS) reselling as a hosted service |
| Elastic | Apache 2.0 | Elastic License | Same — prevent resale without contribution back |

## Terminology Discipline

> [!warning] Not open source
> Calling these licenses "open source" is **incorrect**. The OSI is strict about this, and so should you be.

- There can be legitimate business reasons to use a source-available license
- But don't conflate them with true OSS in your own communications, docs, or marketing

## Comparison to True OSS Licenses

| License Type | OSI-Approved? | Restriction |
|---|---|---|
| MIT / Apache / BSD | Yes | None (permissive) |
| GPL / AGPL / MPL | Yes | Copyleft (distribution / network use / file-level) |
| BSL / SSPL / Elastic / FSL | **No** | Carve-out against competing hosted service |
